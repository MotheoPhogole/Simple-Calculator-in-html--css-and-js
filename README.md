# Modern Calculator

A simple, dark-themed calculator built with vanilla HTML, CSS, and JS. Supports standard arithmetic, exponentiation, and keyboard input.

Created by **Ngwatle Motheo Phogole**.

## Features

* **Basic Operations:** Addition, subtraction, multiplication, division, and exponents (`^`).


* **Keyboard Support:** Use number keys, operators, `Enter` to calculate, and `Esc` to clear.


* **Accessible UI:** Includes ARIA labels and live regions for screen readers.


* **Responsive Layout:** Built with CSS Grid and smooth active button states.



## Files

* `index.html` — Calculator layout and ARIA attributes.


* `CssCalculatorInterface.css` — Dark mode styles and grid layout.


* `JavaScriptCalculatorInterface.js` — Calculator logic and keybindings.



## Usage

Just open `index.html` in your browser.
